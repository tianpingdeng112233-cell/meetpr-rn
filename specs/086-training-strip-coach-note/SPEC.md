## 背景：推进制与日历格

训练推进不看日期：当前训练日 = 计划内按顺序第一个没结算的训练日（`cursorDay`）。周条上的日期只是教练推荐日期，纯展示。10/03 定的 7 天日历格解决了"看不出哪天休息"，但把具体日期印在每一格上，学员一落后（走查当天是 10/9，周条显示 9/21–9/27 且标着 Current week），整排就成了过期日历，看起来像"你迟到了 18 天"。

| 题 | 结论 |
|---|---|
| 1 周条怎么与推进制相容 | 保留 7 格节奏（训练日 / 休息日一眼可见），**格子里去掉日期**，只留星期与 D 序号；教练推荐日期收成周条下方一行小字 |
| 2 周条高度 | 要压矮，但草图里"单行 44 高"太小；取中间尺寸，2A / 2B 二选一待定稿 |
| 3 教练备注 | 移到 hero 卡动作名正下方、重量之上，淡金底、正文字号加大；组备注与动作备注都有时两条都显示，组备注在上 |

## §1 周条：格子去日期

- 训练日格：星期缩写 + 状态图形 + `D{序号}`。不再显示日期。
- 休息日格：星期缩写 + `Rest`（中文"休"）。不再显示日期。
- 格数、起点、休息日判定、横向滚动、选中框与当前训练日两种标记、翻周、`Back to today`、未来训练日只读预览：全部沿用 084 §4 修订，不动。格子仍按教练推荐日期排到对应星期，只是不把日期印出来。
- **推荐日期一行**：周条下方居中一行灰色小字，内容是**所选训练日**的教练推荐日期，用现有文案 `Coach recommends {0}`（中文"教练推荐 {0}"）与现有日期格式（`recommendedDateText`）。所选日已完成时不显示这一行。
- 只读预览卡里原有的那行教练推荐日期删掉（与上面这行重复）。
- 读屏：训练日格读"`W3D1` Mon"，休息日格读"Mon, rest day"；日期不进格子的读屏文字，推荐日期一行自身可读。

## §2 周条：压矮

共同点（2A / 2B 都做）：去掉周数小点；格子因少一层日期而变矮；训练日格与休息日格的宽度比例（1 : 0.7）不变；每个可点格的命中高度不低于 44。

- **2A（推荐）**：换周行保留（左箭头｜`W3` + 状态胶囊 + `0 / 2`｜右箭头），行高压到 32（箭头命中区横向仍 44）；格子两层（星期 / 状态图形与 `D1` 同一行），高约 54。
- **2B**：`W3` + 状态胶囊 + `0 / 2` 并到 `Training history` 那一行的左侧；左右箭头放到格子行的两端；格子三层（星期 / 状态图形 / `D1`），高约 64。比 2A 再省一行，但 7 格可用宽度少两个箭头的位置。

翻到其他周时页头右侧换成 `Back to today` 的规则不变；2B 下周次那一行照常显示所看那一周。

## §3 hero 卡：教练备注上移并加重

现状：备注在卡片最下方（重量、处方、上次成绩之后），12 号灰字、浅灰底；取值是"组备注，没有才用动作备注"，两者都有时动作备注被盖掉。

改为：

- 位置：动作名与 `Ask coach` 那一行的正下方，大号重量数字之上。
- 样式：淡金底圆角块；小标题金棕色、带一个对话图形；正文用主文字色、15 号、行高 21，不截断（全文显示）。
- 内容：
  - 只有组备注（`coach_note`）：小标题 `Coach note · this set`（中文"教练备注 · 本组"）。
  - 只有动作备注（`notes`）：小标题 `Coach note · {动作名}`（中文"教练备注 · {动作名}"）。
  - 两者都有：同一个淡金块里上下两段，组备注在上，中间一条细分隔线；动作备注那段正文 14 号。
  - 都没有（含只有空白字符）：整块不出现，卡片与现状一致。
- 当前组切到下一组时，组备注随之换；动作备注在同一动作的各组间保持。
- 下方分动作组表里已有的动作备注行不动。只读预览与已完成详情不在本项范围。
