# App 115 · 跨日训练续接（Android）

2026-11-26 David 定稿，T2 / P1，随下一班车。先读 CONTEXT.md。本卡沿用 spec 107 全天一览与 101/102 结算同步。

学员默认进入仍未完成的游标训练日时，如果曾在此前的训练日实际打开过同一节，先显示「上次训练，练完了吗？」。训练日按设备当地凌晨 04:00 分界。按学员、计划及训练节分别保留最后打开日期。升级首次使用从真实访问开始。浏览其它节只记对应那节；已完成、交接预览、只看排期、当日返回均不弹。切后台跨日恢复应按当前打开入口核对。

弹层显示上次打开日期、W#D#、组记录数量，常显带值的「实际完成日期」。默认上次打开日期。点「改日期」在层内三列按日选择，上次打开日至本训练日均可选，跨周跨月同理。默认日期一键完成。「继续这节」保留已有记录并消耗当天提醒。移除「点一行可改、可拍」。

选定日期补齐尚未写入的组，已记录组保留。遵循现有写组、同步、视频送达闸门，传 actual_completion_date 到完成接口。服务端成功才跳到新的实际游标，五秒后淡出提示。末节及交接按已有结束状态处理。失败可重试；等待视频或离线不报假成功。completed_at 保持服务器结算时刻。先上线后端 071（迁移 0091）。仅当学员 GET /plans/:id 顶层 actual_completion_date_enabled 为 true 时启用。已经结算的同一节，以服务端首次写入的实际日期为准。部分缺组补写或不确定的提交结果保留已选日期，未补写任何组并明确拒绝时可改日；已补写组则继续与重试均使用原日期。完成回执后重读计划详情，再选新的游标。
