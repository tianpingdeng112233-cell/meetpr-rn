# 动作留言卡片等宽（P1）

David 确认带标题的动作留言卡片等宽，学员发出靠右，教练收到靠左。旧组件设置 88% 最大宽度，短留言会按内容收窄。现用同一比例明确指定宽度，正文自然换行。学员待同步卡和双方已确认卡都使用这个组件。

验收使用长、中、短三条合成留言。Android 模拟器 meetpr16 上挂载实际 ChatExerciseNoteCard，按两端的消息行结构显示。以屏幕像素计，学员发出三卡横坐标均为 171–1026，教练收到均为 54–909，高度随内容变化。此项验证覆盖卡片布局，使用本地数据。

Jest 三种语言的宽度断言在修改前均失败，修后 all-day-view 套件 62 项通过。Standards 和 Spec 独立审查各 0 个未决项。
