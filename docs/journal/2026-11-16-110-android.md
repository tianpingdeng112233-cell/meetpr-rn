## 实装与口径

- `plansRepository.handoff` / `usePlanHandoff` 是正常 current 读取入口，`currentPlanSummary` 只匹配服务端 `current_plan_id`，不在客户端重算锚或日期。zod 接受后端摘要，并为其未提供的旧 shift 字段补默认值。
- 新契约失败（含部署前 404）先读本机有效契约缓存，没有缓存才请求旧列表，复用最近发布排序作部署兼容。401 / 403 继续抛出。缓存按请求者与学员隔离；损坏缓存不阻断回退。旧 `training.workout-snapshot.v1` 格式不改，无新契约缓存时旧快照仍能离线训练。
- `selectCurrentPlan` 仅保留给部署回退与发布通知排序；所有正常训练 current 都走新入口。新接口未部署且无缓存时仍有旧算法的日期 / 发布限制，此时不提供 next 预览，不能把兼容降级当新规则已生效。
- 训练页固定本次会话的 current；奖励页、组保存、编辑、体重填写、相机 / 选片 / 裁剪、视频上传、待同步期间不接受新 current。无锁后下次进入或主动刷新采用最新查询结果，定位游标日。待同步冷启优先旧快照，跨计划箭头也受相同门禁保护。
- 预览使用独立处方组件，不创建组草稿、不装配编辑 / 拍摄 / 完成组件，不覆盖训练快照；比赛 / 体重条保留布局但禁用写入口。空计划不参与跨计划翻页。返回正在练定位游标日；左翻上一周期保留原查看 / 撤销能力。
- 提示记录在本机按学员与计划 id 持久化；点关闭或新周期成功记任一组后消失。预览不会消耗提示。ScrollView 在计划 / 预览态 / 选中日变化时重建，消除沿用旧偏移的来源；Android 实际滚动还需亲验。
- 简体 / 英文在 `RnExtras.json`，繁体沿既有脚本生成；共用训练组件，无 CN / Global 分支。新增颜色 / 字体 / 间距使用现有 design tokens。
- demo-offline 增加下一周期，支持只读翻看、完成后接续和撤销回退；旧 demo ID 保持稳定。
- 五份 fixture 原样复制，逐字节核对与后端来源一致，不运行时跨仓读取。仓内未发现 FOLLOWUPS.md；开工已读 Expo v57 文档与既有定稿。
