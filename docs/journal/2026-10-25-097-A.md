## 实装

- `AndroidUpdateSession` 保留原有 enabled 启用入口，限定 Android。冷启动检查；非 active → active 时，距上次成功检查发出时间严格超过 6 小时才重查。进行中的请求不重入；卸载/禁用时取消请求并移除监听。
- 成功检查时间和已提示的最高 versionCode 只存组件 ref；根布局原本单次挂载，不落盘。后台收到结果时等回前台才提示；提示时记录 versionCode，不依赖用户点「稍后再说」或「下载」，只有更高版本能再次提示。
- `checkForAndroidUpdate` 以 `null` 表示成功检查但无新版本，`undefined` 表示失败或未执行。网络/HTTP/JSON/无效元数据/8 秒超时均不计成功时间，回前台可重试；继续吞错。latest.json 校验结构、下载 URL 和下载重试入口不变。
- `SettingsPage` 在列表末尾显示居中、12pt、`textMuted` 的静态版本文本。读原生 versionName 和 buildVersion，任一缺失或非 Android 时隐藏。简中与英文按卡文案；繁体通过 `npm run i18n:zh-Hant` 生成，没有手改生成文件。
