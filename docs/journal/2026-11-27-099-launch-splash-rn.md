# 2026-11-27 · spec 099 开屏动画 · 安卓 RN

实装方：Claude（David 当面指定「不调用 Codex，就你来做」）。

## 做了什么

- 新增 `src/features/launch/`：时间轴与阶段纯函数（`splash-timeline.ts`，与 iOS 同构）、开屏组件 `LaunchSplash`（原生驱动的 `Animated`，把纯函数按 1/60 秒采样成插值表）、就绪判断 `useLaunchReady`。
- 根布局挂一次开屏层；隐私同意弹窗、安卓更新提示、休息计时引导都等它离开后再出现。
- 就绪 = session 恢复落定；绑定学员再等绑定门走出加载页（绑定门 3 秒内没挂载就不再等，避免卡死在开屏上）。
- 系统启动图 `splash-icon.png` 原来是 1×1 的半透明蓝点，Android 12 以上会被放大成屏幕中间一个紫色方块；换成全透明。
- 删掉「正在验证会话」文案（catalog 与生成的繁体表）；`validating` 页的转圈保留给非冷启动场景。
- 定稿字标 SVG 入 `docs/brand/`。

## 已知差异（spec 已列）

- 系统启动屏只能纯色，动画开头 0.15s 把渐变背景淡入。
- 标语用系统粗体，不做字距收紧动画；字标投影为固定值。
- 系统「移除动画」（过渡动画缩放为 0）会被 RN 判为减弱动态效果，直接显示最后一帧。

## 验证

- `npx jest src/features/launch src/analytics/__tests__/root-layout.test.tsx`：23 条全绿。`npx tsc --noEmit` 与 eslint 对改动文件无输出。
- 演示模式包（`com.meetpr.app.splash099`，arm64）装在 `meetpr16`@5570，冷启动录屏逐帧看过：纸白系统启动屏（无紫色方块）→ 渐变淡入、字标与标语入场、加载线 → 淡出进训练页。字标中心约在屏高 46% 处，与参照稿一致。
- 同一台模拟器过渡动画缩放为 0 时：不播入场，直接进首页。

## 没验的

- 真实后端下的已登录 / 未登录冷启动（只看了演示模式）。
- 弱网下循环加载线的实际画面（只有单测）、从后台切回不重播、带历史老账号从现网 CN 包升级后的第一屏。
- 首次安装时隐私弹窗在开屏之后出现的实际观感（演示模式不弹）。
