3. 小勾把该动作当前值写入原 set-sync 队列，取消只展开；长按补写全部未记录组后进入原完成协调器，保留奖励、撤销与视频等待。旧组队列、快照、视频持久化 key / schema 保持兼容。
4. 所有 API client 请求增加 `X-MeetPR-Caps: set-weight-nullable`。组重量读写 schema 接受 null；旧实际值优先，保留小数精度；只写 RPE 的组接入服务端建议。空重量显示、CSV 空列、e1RM 排除及清理旧缓存点已接线。
5. 每组相机直接进入现有录制组件，左下相册，沿用剪辑、上传、恢复、回放、重拍、删除；compact 图标区分上传与已送达。
6. 新增文本动作留言和双方聊天卡片，首行中英文 canonical 文案，保留第二行起学员原文；发送请求只带 `exercise_ref`，不带 `set_ref` / video。双方卡片复用训练 handoff / 教练日详情跳转。
7. 教练日详情组行匹配处方时显示「按计划」；不匹配显示实际值和处方差异，区间按区间判断。视频反馈、历史与旧聊天卡片的空重量显示「—」；视频回放以组记录的显式 null 优先，不恢复旧视频快照重量。
8. 删除训练页旧开始、补记、整页组录入、逐组完成、休息计时触发、♥、刷新按钮、训练历史和旧组分享入口；设置隐藏组间休息，启动取消旧休息通知。保留休息与旧组件文件、历史 `set_ref` 协议和卡片渲染。
