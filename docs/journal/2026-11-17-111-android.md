## 做了什么

- 训练页可练日恢复手动入口：64 圆环、SVG 进度环、10 秒内金色数字、结束文案及 3 秒回待机；已结算/无计划/无动作、数字面板与其它覆盖层期间隐藏。切 tab 保留组件和墙钟终点。
- 轻点开始/展开、500ms 长按设置并轻震；250–499ms 的半次长按松手不开始计时；移动超过 8 时转拖动，按半屏吸左/右，边距 16，位置设备本地保存。周条以下、完成按钮上方 12 限位。
- R3 直径 280 居中圆盘，±15s、结束、设置入口；R0/R5 直径 340（窄屏等比缩小），两个 112×102 滚轮，每格 34，0:30–10:00/15s 整格吸附，两个 48 开关实际相隔 40。60% 黑罩，点外侧保存/收起；设置不暂停倒计时。
- `RestTimerSession` 管理 idle/running/done、墙钟、0/900 限位、最终 10 秒逐秒震动及到 0 的两个提醒开关；完成今天取消计时与通知。后台 tick 不震动、不清除完成通知；回前台消费原生加时/结束状态，不重播提醒。
- 本地设置迁到 `meetpr.rest-timer.v3.<studentId>`：旧 custom 的 mid 为主项，automatic 默认 180，辅助沿用并截到 600；兼容更早单一时长。旧键只读不再写，不删除旧值。声音/震动默认开，首次设置与气泡用独立的按学员标记，不复用旧说明标记。
- 复用 Android notification 模块：按钮和 receiver 均为 +15s；四种声音/震动组合使用独立 completion channel；前台提示音由原生 notification audio stream 播放短 beep，检查 ringer mode。后台完成通知按开关选声音/震动，双关仍发静默通知。
- 下线 RPE 分档模型、旧设置界面、说明弹窗/规则文件、旧底部条；我的设置入口保持不存在。简繁英文案齐全，已运行 `npm run i18n:zh-Hant`。
- 未新增依赖、未改后端或 iOS。依赖通过本机 npm cache 离线安装，并运行既有 postinstall patch。

## 工程解释与偏离

- 无新增产品行为。spec 的「浮层底 surface2 / 按钮底 surface3」在 RN 映射为现行 `surfaceElevated / surfaceRaised`：仓内 `tokens.test.ts` 禁止使用已归档的 `surface2/3`；未添加颜色。结束按钮沿用现网 `HoldToCompleteButton` 的 `holdTrack / inkOnCTAFill`。
- RN API 将 `rest_seconds` 存在组处方，而 spec 只说当前动作的教练时长：按当前动作的 `set_number` 顺序取第一个非空值；没有时才用主/辅设置。动作类别取 catalog `exerciseType === accessory`，不取计划 `is_main_lift`。
- 退休行为对应的旧测试随代码删除；demo 存储测试只换新数据形状，spec 107「无旧弹窗」回归只把 fixture 设为已看过新引导的学员，原断言保留。未添加 spec 约定之外的新测试 seam，也未加快照。
- 仓内无 Prettier 配置/脚本；对本次完整重写文件使用本机缓存的 Prettier 默认格式并检查，未添加配置或格式化整个旧训练页。
