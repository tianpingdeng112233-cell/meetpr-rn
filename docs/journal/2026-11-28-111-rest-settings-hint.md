# spec 111 · 移除休息设置操作提示

设置圆盘底部仅在保存失败时显示错误。背景按钮继续使用「保存休息设置」作为无障碍名称。

在 meetpr 模拟器的 Global Debug 学员 Demo 打开设置，两档滚轮及两个开关正常显示，盘下方无提示。关闭声音、点空白处、长按圆环重开后声音仍为关闭。随后恢复原设置。[模拟器截图](evidence/111-rest-hint/android.png)

回归测试在旧版读到常驻提示并失败，改后 7 项计时器测试通过，覆盖保存失败、重试和点空白保存。TypeScript、定向 ESLint、繁体词库校验、arm64 Debug 构建通过。
